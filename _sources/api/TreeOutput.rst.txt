TreeOutput S
============

:viewcode:`tree.spad line 494 <tree.spad#L494>` :editcode:`[edit on github] <tree.spad#L494>`

* S: \ :ref:`SetCategory <l53657443617465676f7279>`\ 


This package implements new output for trees. Output depends on two paramenters, maximal depth and maximal number of leaves. Maximal depth can be queried using \ :code:`outputDepth()`\  and set to \ :code:`d`\  using \ :code:`outputDepth(d)`\ . Similarly maximal number of leaves can be queried using \ :code:`outputNofLeaves()`\  and set to \ :code:`n`\  using \ :code:`outputNofLeaves(n)`\ . Default depth is 2 and default number of leaves is 1000. The trees are output until reaching maximal depth \ :code:`d`\ . Leaves are depicted by \ :code:`<v>`\  while the other nodes of depth \ :code:`d`\  list the labels of their children: \ :code:`v-`\ [\ :code:`v1`\  \ :code:`v2`\  ... \ :code:`vk`\ ]. Note further, that the tree grows from left to right and for the edges left to right is depicted from top to bottom. Also, maximal number of leaves that are output is restriced by \ :code:`outputNofLeaves()`\ .

JLPyPari
========

:viewcode:`jpython.spad line 193 <jpython.spad#L193>` :editcode:`[edit on github] <jpython.spad#L193>`


This package provides an experimental Julia Python interface to the number theory library PARI/GP \url{https://pari.math.\ :code:`u`\ -bordeaux.\ :code:`fr/`\ }. \url{\ :code:`https://cypari2`\ .readthedocs.io/en/latest/index.html}. CyPari 2 (\ :code:`cypari2`\ ) must be installed in Julia using CondaPkg.

LeafIndexingTree
================

:viewcode:`tree.spad line 639 <tree.spad#L639>` :editcode:`[edit on github] <tree.spad#L639>`


\ :ref:`LeafIndexingTree <l4c656166496e646578696e6754726565>`\  is a tree where the children of each node are totally ordered from left to right, smaller means left. The root node has an arbitrary label (= value). Each other node has as label the number of leaves in the subtree of its parent node \ :code:`y`\ , consisting of all the childrens left to the edge \ :code:`x`\ -\ :code:`y`\ . These edges are labeled from left to right by 1,2,... Assume that there are exactly \ :code:`l`\  leaves. This setting determines a bijection between {0,1,...,\ :code:`l`\ -1} and the leaves, respectively the paths given as list of edge numbers from the root node to the leaves: \ :code:`rank`\  and \ :code:`unrank`\ . Output is inherited from \ :code:`Tree(NNI)`\  and implemented in the package \ :ref:`TreeOutput <l547265654f7574707574>`\ . See its documentation for more details.

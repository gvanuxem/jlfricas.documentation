Comparable
==========

:viewcode:`catdef.spad line 991 <catdef.spad#L991>` :editcode:`[edit on github] <catdef.spad#L991>`


The class of sets where ordering predicate provided by \ :ref:`ComparableRepresentation <l436f6d70617261626c65526570726573656e746174696f6e>`\  gives mathematical linear order. That is, if \ :code:`x = y`\  then for all \ :code:`z`\ , \ :code:`smaller?(x, z)`\  is equivalent to \ :code:`smaller?(y, z)`\  and \ :code:`smaller?(z, x)`\  is equivalent to \ :code:`smaller?(z, y)`\ . This category exist because declaring \ :ref:`OrderedSet <l4f726465726564536574>`\  may have undesirable consequences, but we still want to use ordering predicate.

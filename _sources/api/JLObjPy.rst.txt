JLObjPy
=======

:viewcode:`jobject.spad line 532 <jobject.spad#L532>` :editcode:`[edit on github] <jobject.spad#L532>`


Convenience domain for Julia Python objects that are used within Julia, and not directly by the underlying FriCAS Common Lisp. The PythonCall package has to be installed in Julia. Note that the PythonCall Julia package uses a similar scheme for Julia Python objects to the one of jlFriCAS for JLObjectType references.

  \ :code:`jlPyApply(mod, func, pyobj)`\  applies the Python function \ :code:`func`\  from the module \ :code:`mod`\  to the Python object pyobj. For example: Numpy needs to be installed, see the Julia package CondaPkg.

     .. code-block:: text

  creates a numpy array from the Python list [1,2,3]. jlPyApply("math", "sqrt", 2) computes the square root of 2.

ConstructorDocumentationHtml¶

api2.spad line 1 [edit on github]

This package generaters Html pages describing all constructors. It is a rewrite of a package by Ralf Hemmecke generating REST form.

documentAll: String -> Void

documentAll(path) takes as argument a path to a file that contains lines in the form: “FILENAME LINENUMBER KIND ABBREV CONSTRUCTOR” which looks, for example, like this “acplot 48 domain ACPLOT PlaneAlgebraicCurvePlot” and writes out for each constructor X a file with name X.html that contains the API description, i.e. docstring and a list of exported function names together with their types. Additionally, the following 3 files will be output: Categories.html -- a list of all categories Domains.html -- a list of all domains Packages.html -- a list of all packages.

documentConstructors: (String, String, XHashTable(String, Record(fn: String, pos: String, ckind: String)), List String) -> Void

documentConstructors(title, kind, csl, cnl) documents all constructors of a certain kind (category, package, domain). csl is basic info about constructors, cnl is list of constructor names.

readConstructors: String -> XHashTable(String, Record(fn: String, pos: String, ckind: String))

readConstructors(path) read the file given by path and store it in a hashtable indexed by the full constructor name. That gives us a structure that can tell for each constructor, in which source file it is defined, and at which line it starts, as well as its kind, i.e. whether it is a category, a domain or a package.

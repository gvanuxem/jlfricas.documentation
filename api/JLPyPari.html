JLPyPari¶

jpython.spad line 193 [edit on github]

This package provides an experimental Julia Python interface to the number theory library PARI/GP url{https://pari.math.u-bordeaux.fr/}. url{https://cypari2.readthedocs.io/en/latest/index.html}. CyPari 2 (cypari2) must be installed in Julia using CondaPkg.

jlPari: (String, JLObjPy) -> JLObjPy

jlPari(pfunc, pyobj) evaluates pfunc using Pari/GP with the argument pyobj as an input.

jlPari: (String, JLObjPy, JLObjPy) -> JLObjPy

jlPari(pfunc, pyobj1, pyobj2) evaluates pfunc using Pari/GP with the arguments pyobj1 and pyobj2 as inputs.

jlPari: (String, JLObjPy, JLObjPy, JLObjPy) -> JLObjPy

jlPari(pfunc, pyobj1, pyobj2, pyobj3) evaluates pfunc using Pari/GP with the arguments pyobj1, pyobj2 and pyobj3 as inputs.

jlPari: JLObjPy -> JLObjPy

jlPari(pyobj) evaluates pyobj using Pari/GP i.e. in Julia this is equivalent to ‘pari(pyobj)’.

jlPari: String -> JLObjPy

jlPari(s) evaluates s using Pari/GP.
